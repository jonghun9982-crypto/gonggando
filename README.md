# 공간도

사무실 배치도 웹앱 (바닥 크기를 m 단위로 설정하고 공간을 배치)

| 기능 | 설명 |
|---|---|
| 바닥 설정 | 가로 m · 세로 m 입력, 공간 이름, 90° 회전 |
| 도형 배치 | 색상 선택, 크기 조정, 이름 지정, 삭제 |
| 저장·불러오기 | JSON 파일로 저장·열기, 그림 내보내기 |

- 파일로 저장하면 PC에서도 유지됩니다.
- 아이폰 홈 화면 앱으로 사용 가능
- 모든 작업은 기기 안에서 처리되며 서버로 보내지 않아요.
